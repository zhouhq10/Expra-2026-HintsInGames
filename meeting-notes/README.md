# Meeting notes

One file per weekly meeting, named `YYYY-MM-DD.md`.

The file is created **before** the meeting with the pre-meeting section filled in (readings + assignments), and updated **during/after** the meeting with discussion, decisions, and next assignments.

## Template

```markdown
# Notes YYYY-MM-DD Week

## Before the meeting

**Readings:**
- ...

**Pre-meeting assignments (from last week):**

---

## Status round
- Name - done / blocked / next

## Main topic
...

## Decisions
- ...

## Assignments for next week
| Who | What | By when | Done when |
|-----|------|---------|-----------|
|     |      |         |           |
```
