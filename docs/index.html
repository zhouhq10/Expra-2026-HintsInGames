Number Sequence Experiment

In this study you will see several number sequences. Your task is to determine the next number in each one.

The experiment has three phases with 25 tasks in total. Each task has a 2:30 time limit, and you score points for solving correctly and quickly.

Hint group (test mode)

Quick recap before you start

  • 4 baseline tasks (no hints) — get a feel for your starting level.
  • 6 training tasks (hint available) — try the lightbulb if you're stuck.
  • 4 test tasks (no hints) — same items as baseline, to measure improvement.

Every task has a 2:30 timer. If time runs out, you get 0 points for that task and the next one begins automatically. A correct answer scores 100 points + a time bonus (faster = more bonus).
